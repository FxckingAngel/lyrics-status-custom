LyricsStatus: first-time setup

Basic users — use the EXE
-------------------------
1. Download `LyricsStatus.exe` from the release's Assets section.
2. Put it in a normal folder, such as:
   C:\Users\your-name\Desktop\LyricsStatus
3. Double-click `LyricsStatus.exe`.
4. The setup panel opens in your browser. A LyricsStatus icon appears in the
   Windows system tray; right-click it to open settings or quit the app.

The EXE is the recommended download. It does not need Node.js, npm, or a
separate launcher file.

Advanced users — use the ZIP
----------------------------
Download `LyricsStatus-for-friend.zip` from the release's Assets section and
extract the whole ZIP to a normal folder before running it. The ZIP includes
the launcher, settings template, documentation, and files useful for manual
inspection or troubleshooting. Do not run the EXE from inside a ZIP preview.

After extracting, run `LyricsStatus.exe`. `Start-LyricsStatus.cmd` is available
as a backup launch path. Do not double-click `LyricsStatusLauncher.ps1`.

Setup steps after choosing a download:
1. The setup panel should open by itself. If it does not, open:
   http://127.0.0.1:8999
2. Open the Account tab.
3. Create or use your own Spotify Developer app at:
   https://developer.spotify.com/dashboard
4. Add this exact redirect URI to that Spotify app:
   http://127.0.0.1:8999/callback/
   The final slash matters.
5. Enter your Spotify Client ID and Client Secret in the panel.
6. Click Authorize Spotify and finish the login in your browser.
7. If the app asks for Discord account credentials, use your own account
   credential only. Treat it like a password. Never send it to anyone or
   commit it to a repository. A normal Discord bot token will not work.
8. Start Spotify and play a song. Give the app a few seconds to detect it.

The app saves your settings in settings.json. Future executable updates replace
the program only; they keep settings.json, the lyric cache, and the saved
rate-limit cooldown. You do not need to set everything up again after updating.

You can make a desktop shortcut to LyricsStatus.exe. Direct EXE launches also
start the updater automatically. A LyricsStatus icon appears in the Windows
system tray; right-click it to open settings or quit the app.

If Spotify authorization returns an error:
- Check that the redirect URI is exactly the one above.
- Make sure the Spotify app owner and account are allowed to use that app.
- Confirm the Client ID and Client Secret were copied without extra spaces.
- Remove and re-add the values in the panel, then authorize again.

If Discord returns 401:
- The Discord credential was rejected or expired. It is not a rate limit.
- Enter your own current credential in the panel and save it.
- Do not use a bot token and do not share account credentials.

If a song has no lyrics, the app tries several lyric sources and matches title,
artist, and duration before using a result. Some songs, edits, languages, and
regions still have no synchronized lyrics available.

This package intentionally does not contain anyone else's Discord credential,
Spotify cookie, Client Secret, or refresh token.

Do not change launcher.json unless you understand the update source. The
launcher only accepts the configured HTTPS manifest and verifies the downloaded
EXE's SHA-256 hash before replacing it.
